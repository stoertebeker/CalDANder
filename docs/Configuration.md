# Configuration

## Environment variables

| Variable | Required | Description |
|---|---|---|
| `ANTHROPIC_API_KEY` | No* | Anthropic API key for the DAN mode AI assistant |

*The app works without a key, but AI features (summarisation, drafting, calendar extraction) will be unavailable.

Create a `.env` file at the project root (copy `.env.example` as a starting point):

```
ANTHROPIC_API_KEY=sk-ant-...
```

## Adding an email account

1. Launch CalDANder and unlock with your master passphrase.
2. Open **Settings** (gear icon in the sidebar).
3. Click **Add account** and fill in the form:

| Field | Example |
|---|---|
| Display name | Work |
| Email address | you@example.com |
| IMAP host | imap.example.com |
| IMAP port | 993 (implicit TLS) or 143 (STARTTLS) |
| IMAP security | `implicit` or `starttls` |
| SMTP host | smtp.example.com |
| SMTP port | 465 (implicit TLS) or 587 (STARTTLS) |
| SMTP security | `implicit` or `starttls` |
| Username | you@example.com |
| Password | your email password or app-specific password |

4. Click **Save**. CalDANder will immediately try to connect to verify the credentials.

> **App-specific passwords:** For Google, Apple, and other providers that enforce 2FA, generate an app-specific password rather than using your account password.

### Common provider settings

| Provider | IMAP | SMTP |
|---|---|---|
| Gmail | `imap.gmail.com:993` (implicit) | `smtp.gmail.com:465` (implicit) |
| Outlook / Hotmail | `outlook.office365.com:993` (implicit) | `smtp.office365.com:587` (STARTTLS) |
| iCloud Mail | `imap.mail.me.com:993` (implicit) | `smtp.mail.me.com:587` (STARTTLS) |
| Fastmail | `imap.fastmail.com:993` (implicit) | `smtp.fastmail.com:465` (implicit) |

## Config file

Accounts are stored in:

```
~/.caldander/config.json
```

The file is created automatically on first save. All passwords are encrypted with AES-256-GCM before being written. The file is created with mode `0600` (owner read/write only).

**Do not edit this file manually.** Use the Settings panel inside the app. If you lose your master passphrase, you will need to delete this file and re-add your accounts.

### Example structure (decrypted view — for reference only)

```json
{
  "accounts": [
    {
      "id": "acc_1",
      "name": "Work",
      "email": "you@example.com",
      "imap": {
        "host": "imap.example.com",
        "port": 993,
        "tls": "implicit",
        "username": "you@example.com",
        "password": "..."
      },
      "smtp": {
        "host": "smtp.example.com",
        "port": 465,
        "tls": "implicit",
        "username": "you@example.com",
        "password": "..."
      }
    }
  ]
}
```

## Master passphrase

The master passphrase is the single key that protects all your stored credentials.

- Minimum 12 characters; use a strong, unique passphrase
- Never stored anywhere — not on disk, not in memory between sessions
- You will be prompted for it every time you start CalDANder
- If forgotten, delete `~/.caldander/config.json` and start fresh
